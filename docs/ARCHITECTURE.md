# Architecture

## Data flow

```
public/data/*.js ──loadData()──▶ src/lib/air.ts (module singleton: stations, weather, places)
                                   │  refreshLive(): ARSO worker, Open-Meteo mixing height, CAMS forecast
                                   ▼
                          src/state/store.ts (zustand)
             ready · version · idx · pollutant · profile · selection · layers · playing
                 │                                   │
        React components                    src/map/airLayers.ts
     (Sidebar, Timeline, pages)         subscribes, pushes into MapLibre;
                                        map clicks → setSelection()
```

* `version` is bumped after every live refresh; components that read `air` subscribe to it.
* `selection` is `null` (city average), a station, a sensitive place, or any clicked spot.
  `readingFor(selection, idx, pollutant)` is the one function that turns it into a number:
  station → its value, place → city value adjusted by the GRAL heating profile, spot → inverse-distance blend.
* Preferences (profile, pollutant, alert level, notifications, layers) persist in `localStorage` (`bl:prefs2`).

## Map

`baseMap.ts` builds the shared base: OpenFreeMap *positron* style, AWS terrain at ×1.5 with a light
hillshade, OSM 3D buildings from z13 and a pale sky. `setSourceTileLodParams` keeps high-zoom tiles
toward the horizon so buildings do not vanish a few streets away when the camera is tilted.

`airLayers.ts` adds: stations/sensors, the 3D smog pool (ERA5 mixing height × city PM),
GRAL heating smoke (lazy, 2.3 MB), CAMx regional field (lazy), sensitive places, the selection marker
and hover labels. `gridLayers.ts` draws the 250 m planning grid for the sensor and heating pages.

## Rules

* `src/lib` is pure: no DOM, no MapLibre. Tests in `src/lib/logic.test.ts`.
* One constant, one place: bands, colours, profiles, endpoints, map defaults → `src/lib/config.ts`.
* `public/data` is generated by `tools/` and never edited by hand.
